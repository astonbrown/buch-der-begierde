\# Buch der Begierde



Interaktives Leseerlebnis mit dynamischer Fragmentauswahl,

Echo-Algorithmus und persistentem Story-Gedächtnis.



\## Live-Demo



https://DEIN\_USERNAME.github.io/buch-der-begierde/



\## Module



\- Wortfragment-Selektor (7 Fragmenttypen, Intensitätssteuerung)

\- Echo der LeserIn (Resonanz-Visualisierung)

\- Geschichte (4 Seiten, annotierte Textfragmente)

\- QR-Scanner (simuliertes Muster-Erkennung)

\- Story-State \& Memory (dynamische Erinnerungsknoten)

\- Eingabe-Panel (Texteingabe mit Gedächtnisverknüpfung)



\## Tech



\- Vanilla HTML/CSS/JS — keine Build-Schritte

\- Google Fonts: Cormorant Garamond + JetBrains Mono

\- Font Awesome Icons via CDN
